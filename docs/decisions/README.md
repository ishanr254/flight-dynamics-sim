# Design Decisions

One file per real design decision (model fidelity, state variable formulation,
software architecture, visualization approach, etc.), written when the decision
is actually made — not reconstructed at the end of the semester. Each entry
should note: what was decided, what alternatives were considered, and why. This
is the primary source material for departmental Questions 4–5 (alternatives
considered / analysis used to select).

Naming: `YYYY-MM-DD-short-slug.md`
